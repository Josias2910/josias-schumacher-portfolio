# Josias Schumacher — Portfolio

Portfolio web personal desarrollado para presentar mi perfil profesional, experiencia, proyectos y conocimientos como desarrollador de software.

El proyecto está enfocado en una experiencia visual moderna, minimalista y dinámica, utilizando animaciones e interacciones para acompañar la navegación.

## 🚀 Tecnologías

- **Astro** — Arquitectura y desarrollo del sitio
- **TypeScript** — Lógica y tipado
- **Tailwind CSS** — Diseño y estilos
- **GSAP** — Animaciones e interacciones
- **Motion** — Animaciones complementarias
- **Node.js** — Entorno de ejecución y gestión de dependencias
- **HTML5 / CSS3** — Estructura y estilos
- **Git / GitHub** — Control de versiones

## ✨ Características

- Diseño responsive
- Arquitectura basada en componentes
- Animaciones e interacciones avanzadas
- Transiciones entre secciones
- Experiencia optimizada para diferentes dispositivos
- Diseño orientado a rendimiento y experiencia de usuario

## 📂 Estructura

El proyecto utiliza una arquitectura basada en componentes de Astro, separando la estructura visual, estilos y lógica de las animaciones para facilitar el mantenimiento y la escalabilidad.

## ⚙️ Instalación y desarrollo

### Requisitos

- [Node.js](https://nodejs.org/) instalado
- npm

### Clonar el repositorio

```bash
git clone https://github.com/Josias2910/josias-schumacher-portfolio.git
cd josias-schumacher-portfolio
```

### Instalar dependencias

```bash
npm install
```

### Iniciar el servidor de desarrollo

```bash
npm run dev
```

El proyecto estará disponible en:

```text
http://localhost:4321
```
